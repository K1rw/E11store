# E11store

متجر عربي لتيشيرتات كرة القدم والأحذية الرياضية والكاجول، والأسعار بالريال القطري.

## تشغيل الموقع
افتح ملف `index.html` في المتصفح، أو فعّل GitHub Pages من إعدادات المستودع لنشره.

## المزايا
- تيشيرتات بسعر 70 ر.ق، مع اختيار المقاس.
- إضافة طباعة الاسم بسعر 25 ر.ق يمكن تطويرها ضمن نموذج الطلب.
- أحذية بين 200 و250 ر.ق.
- سلة مشتريات، تصفية حسب النوع، زر انتهاء الكمية، والمزيد من البضاعة.
- قسم دعم وتواصل.
